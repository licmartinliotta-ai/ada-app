Política de privacidad de Ada

Última actualización: 2 de noviembre de 2026.

Ada es una aplicación de uso personal de Martín Liotta. La usa una sola persona, su dueño, con su propia cuenta de Google.

Qué datos de Google usa

  • Google Drive, solo lectura: busca y lee archivos cuando el usuario lo pide.
  • Gmail: lee mensajes y crea borradores de respuesta cuando el usuario lo pide. Ada no envía correos por su cuenta.

Para qué los usa

Únicamente para responderle al propio usuario: resumir, buscar información y preparar borradores. No se usan para publicidad, no se venden y no se comparten con terceros.

Dónde se guardan

Las credenciales de acceso se guardan en el Llavero de macOS de la computadora del usuario. Para entender cada pedido, fragmentos del contenido pueden enviarse a los proveedores de modelos de lenguaje que usa la aplicación, solo para generar la respuesta. Las notas y documentos que el usuario decide guardar quedan en su base de datos privada.

Uso de datos de las API de Google

El uso y la transferencia de la información recibida de las API de Google cumplen la Política de datos del usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El permiso se puede quitar en cualquier momento desde myaccount.google.com/permissions.
